# M3 Browser Application Implementation Plan

**Goal:** Ship the static, offline-capable playground of TRD §10: paste and file modes running the Rust engine as WebAssembly in a Web Worker, under the §11.3 header policy, in the owner's retro-desktop theme.

**Architecture:** `crates/wasm` wraps `spymonk-redact-core` with wasm-bindgen and is embedded (base64) in the hashed worker script. The page is vanilla TypeScript bundled by Vite into one SRI-protected module and one stylesheet; it talks to the worker only through the validated protocol of §10.5 and renders input-derived text only through text nodes.

**Tech Stack:** Rust 1.99.1, wasm-bindgen 0.2.129, js-sys, zeroize 1.9.1, binaryen 132 (`wasm-opt -Oz`); Node 22.23.3, npm 10.9.9, TypeScript 6.0.3, Vite 7.3.7, Vitest 5.0.3 + jsdom 30.1.2, ESLint 9.39.5 + typescript-eslint 8.71.1, Playwright 1.63.0 + axe-core.

**Spec:** [TRD v2.1](../../TRD.md) §10, §11.2–§11.4, §19.7–§19.8; [PRD v1.1](../../PRD.md). Theme: owner reference image `E:\Work\spymonk-encyclopedia\9043432.jpg`.

## Global Constraints

- CSP exactly as TRD §11.3 (page) and the worker policy; `font-src 'none'`, system fonts only; no third-party resources.
- No `innerHTML`, `outerHTML`, `insertAdjacentHTML`, `document.write`, `eval`, `Function`, string timers (lint-enforced).
- No `localStorage`, `sessionStorage`, IndexedDB, Cache API, cookies; input never in the URL.
- One main-thread ES module and one stylesheet, both with `integrity="sha384-…"`; module-preload polyfill off.
- Paste limit 1 MiB UTF-8; debounce 150 ms; one request in flight plus one pending; 2 s paste watchdog, one worker restart, then `unavailable`; file chunk watchdog 5 s; highlight cap 10,000.
- Status never says "safe"; always "review before sharing".
- WCAG 2.2 AA: labels, polite live region, visible focus, 24×24 px targets, file picker alternative to drag, no horizontal overflow at 320 px, reduced motion.
- The product mark shown on the page is also the favicon; no framework default icons.
- Dependencies pinned exactly, each release at least 14 days old; `npm ci --ignore-scripts`.

## Review Focus

1. A stale worker result (older revision, other options, other rule hash) must never be shown or copied.
2. Worker restart after a watchdog timeout must not resend input and must reach `unavailable` after a second failure.
3. Hidden characters must render as badges while Copy copies the exact sanitized string.
4. File mode must never hold the file on the main thread and must abort a partial stream-to-disk save.
5. The built page must run under the real CSP with Trusted Types enforced (worker creation included).

### Task 1: WebAssembly adapter crate

**Files:** Create `crates/wasm/{Cargo.toml,src/lib.rs,src/offsets.rs}`, `.cargo/config.toml`; modify `Cargo.toml` (member), `crates/core` (wipe buffers on drop).

**Interfaces — Produces (JS names):** `rulesVersion(): string`, `rulesSha256(): string`, `toolVersion(): string`, `sanitizePaste(text: string, email: boolean, privateIp: boolean): PasteResult` with `output: string`, `ranges: Uint32Array` (flat `[start, end, ruleIndex]`, UTF-16 offsets), `summary: SummaryObject`, `errorCode: string | undefined`; `FileJob(email, privateIp, maxLineBytes)` with `push(chunk: Uint8Array): Uint8Array`, `finish(): Uint8Array`, `summary(): SummaryObject`, `takeRanges(): Uint32Array` (UTF-8 offsets).

- [ ] UTF-8 → UTF-16 range conversion unit tests (ASCII, BMP, astral, combining marks, BOM) fail, then pass.
- [ ] Core `Sanitizer` zeroes its text buffers on drop (`zeroize`); wasm layer zeroes owned input and output buffers.
- [ ] Linear memory capped at 512 MiB (`--max-memory`).
- [ ] `cargo test --workspace`, clippy, and the wasm32 build pass.
