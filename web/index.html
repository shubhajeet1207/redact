Redact secrets before you share a log.

Paste a log, a config, or a stack trace. SpyMonk Redact replaces passwords, tokens, private keys, cookies, emails, and home-folder names with placeholders, and leaves the rest of every line untouched.

  • Local. The engine runs in your browser as WebAssembly. Nothing is uploaded.
  • Exact. Only matched values change; line breaks, spacing, and encoding are kept byte for byte.
  • Honest. Pattern matching misses what it cannot recognize. Always review before sharing.

install & verify

Not released yet. No package, archive, or container image has been published. Do not install anything named spymonk-redact from a registry until a signed release appears in the repository.

Planned channels

  • pip, pipx, or uv: a wheel that carries the native command-line binary.
  • Standalone archives for Windows, macOS, and Linux on x86-64 and ARM64.
  • A container image with a pinned digest.
  • This playground, plus an offline bundle you can serve from your own machine.

How you will verify a release

Every artifact will ship with a checksum, Sigstore-signed build provenance, and a software bill of materials. You will check provenance with gh attestation verify, compare checksums with sha256sum --check, and confirm that spymonk-redact --version prints the rule-set hash listed in the release notes. This page’s rule set is %RULES_SHA256%.

Build from source

git clone https://github.com/shubhajeet1207/redact
cd redact
cargo test --workspace --locked
cd web && npm ci --ignore-scripts && npm run build

The build needs the Rust toolchain pinned in rust-toolchain.toml, wasm-bindgen-cli 0.2.129, and Node.js 22.13 or later.

security & privacy

What this page does with your data

  • Pasted text and chosen files are processed in this browser tab and never leave the device.
  • No cookies, no browser storage, no analytics, and no third-party resources. Your input never appears in a URL.
  • The page’s policy forbids network connections from both the page and the engine.
  • Leaving the page clears the editor, the output, and the engine.
  • The web host still sees ordinary request details, such as your IP address and browser, in its access logs.

What it cannot do

  • It finds only what its rules recognize. High-entropy strings without a key or known prefix, credentials split across lines, and personal names are not detected.
  • Redaction does not undo a disclosure. Rotate any credential that was already exposed.
  • Each visit trusts the host to deliver unmodified code. For sensitive material, use the command-line tool or the verified offline bundle.
  • Browser extensions can read pages; they are outside the tool’s control.

Report a problem

Report vulnerabilities privately through the repository’s security advisories. The contact details are also in security.txt. Never include real credentials or logs: reproduce with synthetic values.
